# Ayham Player — مشغّل IPTV لشاشات Android TV / Xiaomi TV

تطبيق عربي/إنجليزي لتشغيل اشتراكات **Xtream Codes** على الشاشة، بواجهة بنفسجية عصرية.

## التحميل على الشاشة (بدون كمبيوتر)
1. ثبّت تطبيق **Downloader** على الشاشة (من متجر Google Play على الشاشة).
2. افتح Downloader واكتب هذا الرابط في خانة الرابط:

```
https://github.com/AyhamAmerAlj/Ayham-Player-New/releases/latest/download/AyhamPlayer.apk
```

3. اسمح بالتثبيت من مصادر غير معروفة لتطبيق Downloader عند السؤال، ثم ثبّت.

## المزايا
- دخول Xtream Codes (سيرفر + مستخدم + كلمة مرور) وحفظ الحساب
- قنوات مباشرة بتصنيفاتها، وأفلام ومسلسلات بأسلوب Netflix (بوسترات + صفوف)
- بحث بالعربي والإنجليزي، مفضلة، مشاهدة لاحقًا، تمت المشاهدة، أكمل المشاهدة
- تقديم/رجوع 10 ثوانٍ (أسهم الريموت يمين/يسار أو الأزرار)
- ترجمة: مسارات داخل الفيديو، أو رابط ملف srt/vtt
- **صوت خارجي للمباريات:** اختر قناة تعليق ثانية، وتحكّم بالتقديم والتأخير بالثواني
- خط Cairo للواجهة

## الريموت داخل المشغّل
| الزر | الوظيفة |
|---|---|
| OK | إظهار أزرار التحكم |
| يمين / يسار | تقديم / رجوع 10 ثوانٍ |
| فوق / تحت (قنوات مباشرة) | القناة السابقة / التالية |
| Menu | قائمة الترجمة والصوت الخارجي والتزامن |

## البناء
يتم تلقائيًا عبر GitHub Actions عند كل push إلى `main`، والناتج في **Releases** باسم `AyhamPlayer.apk`.


## الهاتف (أندرويد)
نفس ملف الـ APK يشتغل على التلفاز والهاتف. على الهاتف يتحول التطبيق تلقائيًا إلى واجهة اللمس:
شريط تنقل سفلي، قنوات كقائمة مع تصنيفات أفقية، شاشة بث مصغّرة، وصفحة تفاصيل مناسبة للطول.
في المشغّل: نقرة = إظهار/إخفاء التحكم، نقرتان يمين/يسار = ±10 ثواني (أو تبديل القناة في البث)،
سحب عمودي يسار = السطوع ويمين = الصوت، وشريط التقدم يُسحب بالإصبع. الترجمة: اختيار ملف من الهاتف أو رابط أو SubDL.
