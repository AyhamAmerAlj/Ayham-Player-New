# Ayham Player Web

موقع خاص (لك فقط) يشتغل على الهاتف والكمبيوتر. خادم Node.js بدون مكتبات تشغيل، يعمل كبروكسي: بيانات اشتراك Xtream تبقى على الخادم ولا تصل للمتصفح أبدًا.

## الميزات
- دخول بكلمة سر (كوكي موقّع، حد محاولات)
- رئيسية، أفلام، مسلسلات (مواسم/حلقات)، قنوات مباشرة، بحث عربي ذكي، مفضلة، سجل، متابعة المشاهدة
- مشغّل HLS (hls.js) مع الجودة/الصوت/السرعة، ترجمة من ملف SRT/VTT، التنقل بين القنوات
- عربي/إنجليزي، تصميم للهاتف والكمبيوتر

## التشغيل
متغيرات البيئة (كلها مطلوبة عدا SESSION_SECRET):
`ACCESS_PASSWORD` (قوية، 12+ حرف) · `XTREAM_URL` · `XTREAM_USER` · `XTREAM_PASS` · `SESSION_SECRET`

محليًا: `npm install && npm start`
Docker/Render: استخدم `Dockerfile` و`render.yaml` (Blueprint)، وأدخل المتغيرات الأربعة.

## الحالة
- الخادم والواجهة مختبَرة مع خادم Xtream تجريبي (دخول، قوائم، بروكسي، تفاصيل، فتح المشغّل).
- تشغيل HLS الفعلي في المتصفح وعلى سيرفرك الحقيقي لم يُختبر.
- ميزة الصوت الخارجي للمعلّق غير موجودة في الموقع (التطبيق فقط).
